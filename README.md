# Rajesh Yaduwanshi — Full Stack Developer Portfolio

A responsive, single-page portfolio website built with **HTML, CSS and vanilla JavaScript**. The design uses a dark navy base with purple-blue gradients and a custom RY monogram made with CSS (no personal photo or screenshot is embedded).

## Sections
- Hero introduction and contact details
- Technology stack and core skills
- Project highlights: Online Test Platform, OMR Processing, Fee Management, E-commerce, Service Booking, Question Extract and Speed Trivia Race
- Professional experience
- Email and phone contact actions

## Tech stack
HTML5 · CSS3 · JavaScript · Laravel · PHP · React.js · Angular · Node.js · Express.js · MongoDB · MySQL · Python · AWS

## Run locally
Open `index.html` in any modern browser. No build command or package installation is required.
